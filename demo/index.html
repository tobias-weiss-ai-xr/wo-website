World-Office Editor Rust-Stack

Unser eigener Document Server (Rust) mit der eigenen Editor-UI. Jeder Editor startet mit einem eingebauten Demo-Dokument — einfach tippen loslegen. Änderungen bleiben sitzungslokal, es wird nichts gespeichert und nichts verlässt dieses System.
